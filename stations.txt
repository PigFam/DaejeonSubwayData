# ===== stations.txt — 역 정보(22개 역) =====
# 하는 일: 노선도에서 역이 놓이는 위치·역명 쓰는 쪽·강조 여부, 경로 화면의 "문 열림" 안내(문방향), 역 팝업의 승강장 형태에 쓰입니다.
#          22개 역(101 판암 ~ 122 반석)이 모두 있어야 파일이 적용됩니다.
# 쓰는 법: 역 하나가 한 덩어리(빈 줄로 구분). 각 줄은 "항목명: 값".
#   역번호: 101~122       역명: 한글 역명       영문: 영문 역명
#   승강장: 섬식 / 상대식 / 복합식   (출처: 대전교통공사 자주하는질문 '승강장 형태')
#   문방향_판암행 / 문방향_반석행: 왼쪽 / 오른쪽 / 양쪽 / 가변 / 미확인  (진행 방향 기준, 내릴 때 열리는 쪽)
#       - 섬식=왼쪽, 상대식=오른쪽은 우측통행을 근거로 한 추론값. 실제 안내와 대조해 확인되면 '근거'에 적습니다.
#       - 종점(판암·반석)은 선로 운용에 따라 달라질 수 있어 확인 전까지 미확인.
#   빠른하차_판암행 / 빠른하차_반석행: 그 방향 열차로 "이 역에 도착"했을 때 계단이 가까운 문 번호(호차-문). 여러 개면 쉼표.
#       - 경로 화면에서 도착역 줄 아래에 "빠른 하차 2-3"으로 표시됩니다(그 번호 문에서 타면 내릴 때 계단이 바로 앞).
#       - 비우거나 줄을 빼면 그 역·방향은 표시하지 않습니다. 종점은 도착하는 방향만 있습니다(판암=판암행, 반석=반석행).
#   엘리베이터_판암행 / 엘리베이터_반석행: 엘리베이터가 가까운 문 번호(자료가 생기면 추가). 있으면 "빠른 하차 2-3, 엘베 1-2"로 붙습니다.
#       - 빠른 하차 값은 2026-11-13 반영(자료 확인: 앱 운영자). 현장과 다르면 고쳐 주세요.
#   좌표: 노선도 캔버스(가로 1000 × 세로 1700, 왼쪽 위가 0,0) 위에서 역 동그라미 중심의 위치 "x, y". 숫자만 고치면 역이 옮겨지고 선도 따라옵니다.
#       현재 모양: 반석~유성온천 왼쪽 세로(x=300) → 갑천~오룡 45도 대각선 → 서대전네거리~판암 오른쪽 세로(x=756).
#   표기: 역명을 선의 왼쪽/오른쪽 어느 쪽에 쓸지(비우면 오른쪽). 명소 점과 도착 배지는 그 반대쪽에 놓입니다.
#   주요역: 예 이면 굵은 글씨·큰 원으로 강조.        근거: 메모(앱은 읽지 않음)
# 예시:
#   역번호: 105
#   역명: 중앙로
#   영문: Jungangno
#   승강장: 섬식
#   문방향_판암행: 왼쪽
#   문방향_반석행: 왼쪽
#   빠른하차_판암행: 2-3
#   빠른하차_반석행: 1-2, 4-3
#   엘리베이터_판암행: 3-1
#   좌표: 756, 1266
#   주요역: 예
#   표기: 왼쪽
#   근거: 승강장=공식 FAQ(섬식); 문방향=섬식+우측통행 추론(미검증)
