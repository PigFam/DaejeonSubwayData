# ===== places.txt — 역주변 명소 =====
# 하는 일: 노선도에서 역 옆에 점과 이름으로 나오고, 터치하면 팝업(종류·역·지도·홈페이지), 역 팝업과 경로 화면의 명소 목록에도 쓰입니다.
# 쓰는 법: 한 줄 = 명소 하나. 항목은 쉼표(,)로 구분. 순서는
#   역명, 명소한글, 명소영문, 표시조건, 종류, 종료일, 광고, 홈페이지
#   역명·명소한글만 필수. 나머지는 비워도 됨(중간을 비우면 쉼표는 남기고, 맨 뒤는 통째로 생략). 항목 안에 쉼표는 쓰지 마세요.
#   역명: 판암, 신흥, 대동, 대전, 중앙로, 중구청, 서대전네거리, 오룡, 용문, 탄방, 시청, 정부청사, 갈마, 월평, 갑천,
#         유성온천, 구암, 현충원, 월드컵경기장, 노은, 지족, 반석 ("중앙로역"처럼 '역'을 붙여도 되고 역번호 101~122도 됨)
#   표시조건: 노선도를 이만큼 확대했을 때부터 보임. 1.2 = 조금만 확대해도(앱은 1.2배 미만에서는 어떤 명소도 안 보임),
#             1.5 = 앱 시작 배율부터, 2.0 = 두 배로 확대해야, 4.0 = 최대 확대 때만. 비우면 1.2. 이름 글자는 1.6배 이상에서만 보임.
#   종료일: YYMMDD 6자리. 그날 밤 11:59까지만 보이고 그 뒤엔 노선도·팝업·경로 화면 어디에도 안 나옴(줄은 남겨 둬도 됨). 비우면 계속.
#   광고: "광고"라고 적으면 주황 점 + "광고" 배지.   홈페이지: 주소를 적으면 팝업에 "홈페이지" 버튼.
# 예시:
#   중앙로, 성심당 본점, Sungsimdang, 1.2, 빵집, 261231, 광고, https://example.com
#   정부청사, 한밭수목원, Hanbat Arboretum, 1.6, 공원
#   대전, 중앙시장, Jungang Market, 2.0, 시장
# 줄 순서는 노선도 순(반석 → 판암)으로 두면 역별로 한눈에 보입니다(앱은 순서와 무관).
