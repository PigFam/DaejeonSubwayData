# 대전 지하철ㆍ명소 — 데이터

안드로이드 앱 **대전 지하철ㆍ명소**(대전 도시철도 1호선 도착정보)가 사용하는 데이터 파일입니다.
앱은 켤 때·다시 앞으로 올 때마다(그리고 켜 둔 동안 1시간마다) `version.txt`의 값만 먼저 확인하고,
값이 바뀌었을 때만 나머지 파일을 전부 내려받아 검증한 뒤 한꺼번에 교체합니다(검증에 실패하면 기존 데이터 유지). 올린 직후부터 반영됩니다.

모든 파일은 UTF-8 텍스트이고, 줄 맨 앞이 `#`이면 주석입니다. 파일마다 머리 주석에 **하는 일 → 쓰는 법 → 예시**가 적혀 있고,
`----- 아래부터 실제 데이터 -----` 아래가 실제 데이터입니다. 날짜는 어디서나 **YYMMDD 6자리**(예 `261225`)로 적습니다.

| 파일 | 하는 일 | 언제 고치나 |
|---|---|---|
| `version.txt` | 데이터 묶음 버전. 이 값이 바뀌어야 앱이 나머지를 새로 받음. `날짜(YYMMDD)-그날 몇 번째`, 예 `261107-1` | 다른 파일을 고칠 때마다 함께 |
| `notice.txt` | 앱 상단 빨간 배너 공지. `내용:` 뒤에 여러 줄 가능, 주소(https://… / www.…)는 터치 한 번에 열림, `종료:` 시각이 지나면 자동으로 사라짐 | 운행 장애 때 |
| `places.txt` | 노선도 명소 점·이름·팝업. 한 줄에 하나: `역명, 명소한글, 명소영문, 표시조건, 종류, 종료일[, 광고, 홈페이지]` | 명소·광고 추가/종료 때 |
| `holidays.txt` | 평일 시각표/휴일 시각표 판정. `261225: 휴일   # 성탄절`. 평일에 걸린 공휴일만 적음 | 1년에 한 번 |
| `config.txt` | 문의 이메일, 중간종착역 | 거의 안 바꿈 |
| `stations.txt` | 22개 역의 승강장 형태, 문 방향, 빠른 하차 문 번호(`빠른하차_판암행: 2-3` — 그 방향으로 그 역에 도착했을 때 계단이 가까운 문), 엘리베이터 문 번호, 노선도 좌표·역명 표기 쪽·주요역 | 문 방향·빠른 하차 자료가 바뀔 때 |
| `timetable.csv` | 열차 시각표 본체(대전교통공사 공개 시각표를 변환) | 시각표 개정 때(스크립트로 생성, 손으로 고치지 않음) |
| `segments.csv` | 인접 역 소요시간(종착역 도착 시각 추정용) | 위와 함께 생성 |
| `update.txt` | 앱 업데이트 강제·권장. `최소앱버전:`보다 낮은 앱은 제목·내용·[업데이트] 화면으로 막고 위젯엔 "업데이트 필요", `권장앱버전:`보다 낮으면 닫을 수 있는 배너. `업데이트주소:` 비우면 Google Play | 긴급 업데이트 때 |
