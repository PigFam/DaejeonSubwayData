# ===== update.txt — 앱 업데이트 안내(공개 저장소 전용, 앱에 내장하지 않음) =====
# 하는 일: 앱 버전(versionCode)과 아래 숫자를 비교해 업데이트를 강제하거나 권합니다. 파일이 없거나 숫자가 0이면 아무것도 안 함.
#   최소앱버전: 이 숫자보다 낮은 앱은 "제목·내용·[업데이트]" 화면으로 막힙니다(닫기 없음). 위젯에는 "업데이트 필요"만 보임.
#   권장앱버전: 이 숫자보다 낮은 앱에는 닫을 수 있는 파란 배너("새 버전 | 권장안내 문구 · 업데이트 ✕"). ✕를 누르면 같은 숫자엔 다시 안 뜸.
#   업데이트주소: [업데이트] 버튼·배너·위젯이 여는 곳. 비우면 Google Play의 이 앱 페이지.
#   제목 / 내용: 막는 화면의 글. 내용은 "내용:" 뒤에 줄을 이어 쓰면 여러 줄(다음 항목 전까지).
#   권장안내: 배너 문구(비우면 "새 버전이 나왔어요.").
# 평소: 최소앱버전·권장앱버전을 배포 중인 가장 낮은 versionCode 이하로 두면 아무 화면도 뜨지 않습니다.
# 긴급: 최소앱버전을 새 versionCode로 올리고 version.txt 도 올리세요. 되돌리려면 숫자를 내리고 version.txt 를 또 올리면 됩니다.
# 예시(2 미만은 막고, 3 미만에는 권유):
#   최소앱버전: 2
#   권장앱버전: 3
#   업데이트주소:
#   제목: 업데이트가 필요합니다
#   내용: 중요한 시각표 오류가 고쳐졌습니다.
#   업데이트 후 이용해 주세요.
#   권장안내: 새 버전이 나왔어요.
# ----- 아래부터 실제 데이터 -----
최소앱버전: 1
권장앱버전: 1
업데이트주소:
제목: 업데이트가 필요합니다
내용: 최신 버전으로 업데이트 후 이용해 주세요.
권장안내: 새 버전이 나왔어요.
